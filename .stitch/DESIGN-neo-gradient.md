# Design System: Neo Gradient
**Project ID:** 7990834098475031539

## 1. Visual Theme & Atmosphere
This design system is for ClauseWall, an AI contract analysis tool for Indian consumers. The visual language should scream "AI-powered" and "next generation." Gradients are a core visual element — from text to borders to backgrounds. The interface feels like it's alive with data, analyzing contracts in real-time. This is the most visually striking option — designed to make screenshots go viral. Every element feels like it belongs in a sci-fi command center. Data visualizations (gauges, graphs, proof trees) are the star of the show.

- Default Mode: Dark mode
- Mood: Futuristic, AI-native, data visualization heavy
- Style: Animated gradient meshes in background (very subtle), Gradient text for key headlines, Cards with glowing gradient borders, Data visualization elements feel native, Particle effects or subtle dot grids in backgrounds, Charts and graphs are first-class citizens

## 2. Color Palette & Roles
- **Background**: Deep space (#050510)
- **Surface**: Dark blue-black (#0c0c1d)
- **Cards**: Dark with gradient borders (#12122a)
- **Primary accent**: Gradient (cyan #06b6d4 to blue #3b82f6)
- **Secondary accent**: Gradient (purple #8b5cf6 to pink #ec4899)
- **Text primary**: Bright white (#ffffff)
- **Text secondary**: Blue-gray (#7dd3fc at 60%)
- **Borders**: Gradient borders (1px, animated subtle shift)

**Risk Indicators (4-Tier System):**
- **Success/Safe**: Neon green (#4ade80)
- **Warning**: Electric amber (#fbbf24)
- **Danger**: Neon red (#f87171)
- **Illegal/Critical**: Neon purple (#c084fc)

## 3. Typography Rules
- **Font family**: Space Grotesk or Outfit
- **Headings**: Bold, wide, futuristic
- **Body**: Regular, clean contrast against dark background

## 4. Component Stylings
- **Corner roundness**: Medium (8px)
- **Borders**: Gradient borders that subtly animate
- **Effects**: Glow effects behind important elements
