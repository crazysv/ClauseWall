# ClauseWall UX Reset Brief

## Core Problem
ClauseWall has powerful features, but too many of them compete at the same level. The product can feel feature-rich but overwhelming, especially for users who are not confident with law, contracts, or risk analysis.

The redesign should make the app feel:
- clear
- guided
- trustworthy
- calm
- capable without being intimidating

## Product Principle
Do not rebuild the engine.

We are reorganizing and clarifying the cockpit:
- keep existing features working
- keep existing logic intact
- improve how users discover, understand, and act

## User Types

### First-time user
Needs:
- a simple starting point
- clear explanation of what will happen
- plain-language results
- recommended next action

### Returning user
Needs:
- access to saved contracts and results
- a clear next task
- shortcuts to repeat workflows

### Power user
Needs:
- deeper analysis tools
- simulations
- monitoring
- document comparison
- advanced workspaces

## UX Goals
1. A new user should know where to start within 5 seconds.
2. The product should explain what it does before showing advanced tools.
3. Results should prioritize meaning and guidance before detail.
4. Advanced features should be accessible but not forced into the primary flow.
5. Motion should support comprehension, not performative spectacle.

## Non-Negotiables
- no feature removals by accident
- no logic regressions
- no API rewiring unless explicitly approved
- no breaking existing routes or user workflows

## Success Criteria
- users feel less overwhelmed
- top-level navigation becomes intent-based
- advanced tools move into a deeper workspace layer
- major pages feel self-explanatory
- design feels premium and calm, not theatrical or aggressive
