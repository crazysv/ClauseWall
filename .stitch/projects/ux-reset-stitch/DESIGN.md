# ClauseWall UX Reset Design System

## Design Direction
ClauseWall should feel like a calm forensic product:
- professional
- trustworthy
- precise
- readable
- slightly technical

Not:
- loud brutalism
- over-cinematic spectacle
- hacker fantasy
- intimidating legal theater

## Visual Character

### Shell
- background: deep charcoal, not pure black everywhere
- primary canvas: `#0b0d10`
- panel surface: `#111418`
- elevated surface: `#161a1f`
- subtle separators: `#252b33`

### Accent Palette
- primary trust accent: cyan-blue
- safe/fair accent: emerald
- caution accent: amber
- severe accent: red
- neutral text: stone/gray ramp

Suggested tokens:
- primary action: `#5ab2ff`
- primary action dim: `#11263a`
- safe: `#36c78b`
- caution: `#e2a93b`
- danger: `#e05b5b`

## Typography
- UI font: clean sans or mono-accent pairing
- system labels: mono, uppercase, tracked
- body copy: plain-language, readable, medium contrast
- document/legal longform: preserve serif only where it improves reading

## Components

### Panels
- 1px borders
- low-radius or squared corners
- no thick shadows
- subtle layered contrast instead of offset brutality

### Buttons
- clear hierarchy
- primary: filled or tinted, calm emphasis
- secondary: outlined
- tertiary: inline text or ghost

### Inputs
- dark field surfaces
- 1px border
- strong focus ring or border shift
- no press-down gimmicks

### Tags and badges
- small
- semantic color only
- never noisy

## Motion Language
Use motion for:
- step transitions
- reveal ordering
- loading progress
- panel expansion
- action confirmation

Avoid:
- long scroll narratives on core product pages
- distracting looping motion
- motion that delays understanding

## Page Tone

### Home
- reassuring
- trust-first
- simple

### Analyze
- guided
- clear
- friction-light

### Results
- explanatory
- supportive
- plain language first

### Workspace
- denser
- more technical
- still structured and readable
