# ClauseWall Information Architecture

## Product Structure

### 1. Home
Purpose:
- establish trust
- explain what ClauseWall does
- present the main user paths

Primary CTAs:
- Analyze a contract
- See how it works
- Explore monitoring

### 2. Analyze
Purpose:
- guided intake for upload or paste
- explain privacy
- explain what the user gets next

Visible:
- upload or paste
- document type / jurisdiction
- privacy explanation
- single primary CTA

Hidden or secondary:
- advanced technical settings
- secondary tools

### 3. Results
Purpose:
- help the user understand the contract
- explain risk in plain language
- recommend what to do next

Visible:
- overall summary
- key risks
- what this means
- recommended actions

Secondary:
- clause details
- proof / evidence details
- advanced analysis modules

### 4. Actions
Purpose:
- let the user act on the findings

Grouped tools:
- Negotiate
- Complaint
- Letter
- Compare
- Evidence
- Timebomb

### 5. Monitor
Purpose:
- ongoing alerts and tracking

Grouped tools:
- Watchdog
- law changes
- reminders / deadlines
- notification settings

### 6. Workspace
Purpose:
- advanced tools for deep analysis

Grouped tools:
- Vault
- State Machine
- Ruin Calculator
- advanced simulations
- specialist analysis tools

## Recommended Top Navigation
- Analyze
- Contracts
- Actions
- Monitor
- Workspace

## Feature Placement

### Analyze
- Upload
- quick scan
- intake and privacy controls

### Contracts
- results history
- saved analyses
- verification views

### Actions
- negotiate
- complaint
- letter
- compare
- evidence
- deadline response tools

### Monitor
- watchdog
- policy changes
- alerts

### Workspace
- vault
- state machine
- ruin calculator
- other advanced intelligence tools

## Progressive Disclosure Rule
- beginners see summary and next step
- intermediate users can expand details
- power users can open advanced tools

Advanced functionality should never crowd the initial decision path.
