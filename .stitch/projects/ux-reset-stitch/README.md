# UX Reset Stitch Project

This is the clean redesign workspace for the ClauseWall UX reset.

Purpose:
- redesign the product experience without breaking working features
- use Stitch-first exploration before implementation
- define information architecture before page-by-page UI work

Primary rule:
- preserve existing logic and working flows
- change structure, emphasis, navigation, copy, and presentation

Project files:
- `BRIEF.md`: product goals and user experience principles
- `IA.md`: information architecture and navigation model
- `DESIGN.md`: visual system and motion language
- `MOTION.md`: dedicated motion principles and guardrails
- `prompts/`: Stitch-ready screen prompts

Initial screen order:
1. Home
2. Analyze
3. Results
4. Workspace Hub
