[Guided contract intake screen for ordinary users. Calm, self-explanatory, structured, privacy-aware. Feels like a trusted assistant helping a user start safely.]

**DESIGN SYSTEM (REQUIRED):**
- Platform: Web, responsive
- Palette: Deep Charcoal (#0b0d10), Surface (#111418), Input Surface (#161a1f), Primary Action Cyan (#5ab2ff), Safe Emerald (#36c78b), Caution Amber (#e2a93b), Neutral Border (#252b33)
- Styles: 1px borders, low-radius corners, minimal shadows, mono labels for system metadata, plain-language instructional copy

**PAGE STRUCTURE:**
1. **Header:** Compact product header with breadcrumb or section label showing this is the analysis entry point.
2. **Intro Block:** Short explanation of what the user can upload, what ClauseWall will do, and how long it usually takes.
3. **Primary Intake Card:** Upload area and paste-text option, but presented as one guided module rather than multiple competing widgets.
4. **Context Controls:** Document type, jurisdiction, and privacy controls shown clearly but not overpowering.
5. **What You’ll Get:** Small preview row showing expected outputs: risk summary, key clauses, recommended actions.
6. **Primary CTA:** One dominant action to start analysis.
7. **Supportive Secondary Info:** Small FAQ or helper text about privacy, supported file types, and what happens next.

**SPECIAL NOTES:**
- Minimize branching and visual clutter.
- Make privacy explanations simple and reassuring.
- Use motion only for state transitions and progress feedback.
